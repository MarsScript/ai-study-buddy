# AI Study Buddy — Cloudflare Pages edition

This is a **starter website**, with Supabase email sign-in, saved notes, saved flashcards, quiz history and server-side AI features (Gemini). White-and-blue responsive design. No PayPal billing yet; Premium is marked "coming later".

## Upload this project to GitHub

1. Open `https://github.com/MarsScript/ai-study-buddy` and click **uploading an existing file**.
2. **Unzip this download on your computer first.** Upload the **contents** of this folder, including `public/`, `functions/`, and `README.md`. Do not upload the ZIP itself or a nested parent folder. GitHub’s browser upload can handle files from folders; verify that `public/index.html` and `functions/api/ai.js` appear at the repository root.
3. Commit changes to `main`.

## Deploy as a Cloudflare PAGES project (not Workers)

Cloudflare's new Create application flow defaults to Workers (`npx wrangler deploy`). For this package use **Continue to Pages** -> **Connect to Git** -> choose `MarsScript/ai-study-buddy` -> build command: **leave blank** -> output directory: `public` -> Deploy. Cloudflare Pages automatically picks up the `functions/` directory.

Do NOT use the Workers screen shown with `npx wrangler deploy`: this project targets Pages.

## Supabase setup after deploying

In Supabase Authentication > URL Configuration:
- Site URL: the actual Cloudflare Pages URL generated by deployment, e.g. `https://ai-study-buddy.pages.dev`
- Add Redirect URL: same exact site URL plus `/**` (Cloudflare-generated address may differ).
- Email confirmation is currently enabled. For real student signups check Supabase's email send limits; configuring custom SMTP may be necessary at scale.

Public Supabase URL and **publishable** key are inside `public/app.js`. Never place Supabase secret keys or Gemini keys in GitHub.

## Enable AI later

In Cloudflare Pages project > Settings > Variables and Secrets, add **encrypted Secret** named `GEMINI_API_KEY` containing your Gemini API key, and redeploy. Optional text variable `GEMINI_MODEL` can override the default `gemini-2.5-flash-lite` if that model is not available in your region/free tier. No Gemini key is needed for authentication and saving notes.

**Before a public launch** add server-enforced per-user AI request limits, bot prevention, spending limits / quotas, observability, privacy policy, terms and deletion workflows. The current AI endpoint authenticates users, but does not rate-limit authenticated users and could exhaust API quotas. Never set a paid AI plan or billing without understanding charges.

## Current scope / limitations
- Starter MVP, not a production-audited service; test auth flows and access policies before accepting real users.
- The supplied SQL in the chat creates `study_notes`, `flashcards`, and `quiz_results` with RLS. This website depends on those existing tables.
- The app's save functions create rows, but existing records cannot be edited (only opened as new drafts and deleted).
- No PayPal integration or subscription entitlements yet. $3.99/month is a future plan, not active checkout.
